Privacy policy

Cloud SSD is a personal, non-commercial tool used only by its owner.

  • It accesses Google Drive with the drive.file scope: only files and folders that Cloud SSD itself created.
  • Files are transferred directly between the user's computer and Google. No data is sent to, or stored on, any server operated by the developer.
  • Access tokens are stored only on the user's own computer.
  • No data is sold, shared, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/connections.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Last updated: 10 November 2026.
